## 简介 / Overview
该仓库旨在将日常工作中积累的 AI 能力模块化、文档化，方便复用与分享。内容包括但不限于：模型训练脚本、数据处理管道、示例笔记、工具脚本与最佳实践文档。

This repo aims to modularize and document AI-related skills accumulated in daily work for reuse and sharing. Contents include, but are not limited to: training scripts, data preprocessing pipelines, example notes, utility scripts, and best-practice documentation.

## 快速开始 / Quick Start

1. 克隆仓库 / Clone the repo
   git clone https://github.com/leotse28/AI_skill_library.git

2. 进入目录 / Enter the directory
   cd AI_skill_library

3. 根据具体示例查看 README 或脚本说明并安装依赖
   - 每个子目录通常包含自己的说明文件（README.md）和依赖说明（requirements.txt / environment.yml）。

4. 建议使用虚拟环境 / Recommended: use a virtual environment
   python -m venv .venv
   source .venv/bin/activate  # macOS / Linux
   .venv\Scripts\activate     # Windows
