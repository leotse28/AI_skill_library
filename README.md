## 简介 / Overview
该仓库旨在将日常工作中积累的 AI 能力模块化、文档化，方便复用与分享。内容包括但不限于：模型训练脚本、数据处理管道、示例笔记、工具脚本与最佳实践文档。

This repo aims to modularize and document AI-related skills accumulated in daily work for reuse and sharing. Contents include, but are not limited to: training scripts, data preprocessing pipelines, example notes, utility scripts, and best-practice documentation.

## 特性 / Features
- 中文与英文注释示例混合，便于跨语言团队使用。
- 实用脚本：数据清洗、模型训练、评估与部署辅助脚本。
- 示例目录：包含端到端的小型示例与说明。
- 可扩展结构：按主题/任务划分模块，便于添加新内容。

- Bilingual comments/examples to support cross-language teams.
- Utility scripts for data cleaning, training, evaluation, and deployment helpers.
- Example folders with end-to-end small demos and explanations.
- Extensible structure organized by topic/task for easy additions.

## 快速开始 / Quick Start

1. 克隆仓库 / Clone the repo
   git clone https://github.com/leotse28/AI_skill_library.git

2. 进入目录 / Enter the directory
   cd AI_skill_library

3. 根据具体示例查看 README 或脚本说明并安装依赖
   - 每个子目录通常包含自己的说明文件（README.md）和依赖说明（requirements.txt / environment.yml）。

4. 建议使用虚拟环境 / Recommended: use a virtual environment
   python -m venv .venv
   source .venv/bin/activate  # macOS / Linux
   .venv\Scripts\activate     # Windows

## 使用示例 / Usage Examples
- 查看某个示例目录（例如：examples/text_classification）并按照其中的 README 执行。
- 运行训练脚本示例：
  python examples/text_classification/train.py --config configs/text_classification.yaml

- Inspect example folders (e.g., examples/text_classification) and follow their README.
- Example run:
  python examples/text_classification/train.py --config configs/text_classification.yaml
